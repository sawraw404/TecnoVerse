# TecnoVerse web

Next.js 16 frontend for TecnoVerse. It talks only to the Python API in `../tecnoverse/api.py`, from the server side.

```bash
npm install
npm run dev      # needs the API on http://127.0.0.1:8000 (or set API_URL in .env.local)
npm run lint
npm run build
```

See the repository README for the full setup.
